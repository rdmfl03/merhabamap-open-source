# Security Policy

## Reporting a vulnerability

Please do not open a public issue containing exploit details, credentials, personal data or private infrastructure information.

Report security and privacy issues to **info@merhabamap.com** and include:

- the affected package or behavior
- the potential impact
- safe reproduction steps
- a suggested mitigation, if available

We aim to acknowledge new reports within five working days. For a suspected personal-data incident, prefix the subject with `[DSGVO]`.

## Scope

This repository contains a deliberately limited public snapshot. Production infrastructure, production data and private operational systems are out of scope and are not stored here.

## Contributor expectations

- never commit credentials or real user data
- use placeholders in examples and tests
- keep consent purposes separated
- preserve conservative defaults
- add regression tests for security-sensitive fixes
